## Webdocs

The `theme.toml` metadata declares the MIT license for Webdocs. The current repository version does not include a `LICENSE` file in its root; check the repository before redistributing the theme and make sure to include the applicable license text.

## Fonts

The theme includes Inter and Google Sans Code in `assets/fonts/`. Each family includes its own `OFL.txt` file; refer to the relevant file before redistributing or modifying the font files.

- Inter: `assets/fonts/inter/OFL.txt`
- Google Sans Code: `assets/fonts/google-sans-code/OFL.txt`

Retain the licenses and attribution notices accompanying these resources when redistributing the theme.
