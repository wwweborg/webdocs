## [0.1.0] - 2026-11-25

### Added

- Hugo theme for documentation sites.
- Responsive design with dark mode based on system preference.
- Navigation with sidebar menu, breadcrumbs, page table of contents, and previous/next links.
- Shortcodes for callouts, badges, cards, accordions, icons, steps, and tabs.
- Copy code blocks and tab controls with keyboard support.
- Dismissible announcements and repository link configuration from `hugo.toml`.
- Build and deployment configuration for Netlify.
