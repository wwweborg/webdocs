## What is Webdocs

**Webdocs** is a modern theme built with **Hugo**, designed specifically to create technical documentation sites for web projects or any other type of software. It offers a clean interface, with soft borders and typography designed for comfortable long-form reading.

## Features

- **Built-in shortcodes:** Includes essential components for frictionless documentation: callouts, badges, cards, collapsibles (`details`), icons, numbered steps, and tabs. Code blocks and inline code work directly with native Markdown syntax.
- **Automatic light and dark mode:** It natively adapts to the user's operating system color preference, with no manual configuration needed.
- **Vanilla architecture:** Built only with pure **HTML**, **CSS**, and **JavaScript**, with no external frameworks or heavy dependencies.
- **Static performance with Hugo:** Generates fast, lightweight sites ready to deploy on any server or CDN without heavy server-side processes.
- **Evolving (Beta):** This is a beta version of the theme and will continue to receive improvements and new features in upcoming updates.
- **Open source:** You can use, modify, and distribute the theme freely, with no ties to subscriptions or closed platforms.
- **Support and contributions:** If you find a bug or want to suggest improvements, you can open an issue or collaborate in [our GitHub repository](https://github.com/wwweborg/webdocs/issues).
